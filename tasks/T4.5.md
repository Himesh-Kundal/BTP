## Goal
Implement `backend/module_generator.py` to generate complete top-level Design F modules:
1. Instantiates all $(N/N_t) \times (K/K_t)$ tile cores.
2. Constructs adder trees per output tile over tile dimension $j$ and incorporates constant bias terms.
3. Implements the Design F registered wrapper with synchronous active-low reset, valid handshaking, and fixed latency $L=1$.
4. Runs simulation verification on a real $8 \times 16$ tile extracted from SmolLM2.
5. Generates the full $576 \times 576$ layer and measures/freezes generation time and Verilog file size budgets in `state/STATE.md`.
