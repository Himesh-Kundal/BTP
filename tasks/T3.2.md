## Goal
Implement symmetric INT8 per-output-channel weight quantization strictly adhering to Rule N2: round-half-to-even float64 computation, range $[-127, 127]$, zero-row scale fallback, and mathematical property guarantees.

## Acceptance (executable)
- [x] `pytest tests/test_quantization.py` passes
- [x] Per-output-channel scale: $s_w[n] = \max |W[n, :]| / 127.0$ computed in float64
- [x] Zero-row handling: if all elements in row $n$ are 0, $s_w[n] = 1.0$ and quantized row is all 0
- [x] Rounding mode: `rint` (round-half-to-even), matching NumPy / Python float64 reference
- [x] Quantized range: strictly clipped to $[-127, 127]$ (value $-128$ is explicitly rejected/clipped)
- [x] Mathematical property test: $|W[n, k] - s_w[n] \cdot W_q[n, k]| \le s_w[n] / 2 + 10^{-12}$ for non-clipped entries

## Plan (before coding)
- Implement `quantize_weights(W)` in `compiler/quantization.py`.
- Write unit tests and mathematical property tests in `tests/test_quantization.py`.
- Test on both synthetic corner-case matrices and real SmolLM2-135M dumped weights.

## Evidence (after)

  - 10 randomized matrices with varied dynamic ranges satisfy the quantization error bound: $|W - s_w \cdot W_q| \le s_w / 2 + 10^{-12}$.
