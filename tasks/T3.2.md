## Goal
Implement symmetric INT8 per-output-channel weight quantization strictly adhering to Rule N2: round-half-to-even float64 computation, range $[-127, 127]$, zero-row scale fallback, and mathematical property guarantees.

## Acceptance (executable)
- [ ] `pytest tests/test_quantization.py` passes
- [ ] Per-output-channel scale: $s_w[n] = \max |W[n, :]| / 127.0$ computed in float64
- [ ] Zero-row handling: if all elements in row $n$ are 0, $s_w[n] = 1.0$ and quantized row is all 0
- [ ] Rounding mode: `rint` (round-half-to-even), matching NumPy / Python float64 reference
- [ ] Quantized range: strictly clipped to $[-127, 127]$ (value $-128$ is explicitly rejected/clipped)
- [ ] Mathematical property test: $|W[n, k] - s_w[n] \cdot W_q[n, k]| \le s_w[n] / 2 + 10^{-12}$ for non-clipped entries
