# T6.6 — Regression Test Runner and Results File
Status: in_progress
Phase/Gate: P6 / G6     Tags: [verification, tooling]     Estimate: 1h
Depends on: T6.1–T6.5    Spec refs: docs/06 §A3, §A8, docs/04 §4 (T6.6)

## Goal
Implement a standalone regression runner and Makefile target `make regression`:
1. Execute full verification suite:
   - Level L0 (toy 1x3, 2x4)
   - Level L1 (synthetic shapes across N, K, tile grids, weight and input classes)
   - Level L2 (real SmolLM2 tiles with real captured activations)
   - Level L3 (real SmolLM2 slices across all 7 projection types at layers 0, 14, 29)
   - Cross-simulator verification (Icarus vs Verilator)
   - Static weight audits
   - Full mutation matrix M1–M9
2. Record execution metrics into structured JSON: `results/regression.json` including:
   - git commit hash, timestamp, platform/tool versions
   - per-suite and per-test status, duration, vectors tested, mismatches
   - total tests, passed, failed, wall time
3. Ensure regression is fully reproducible and deterministic.
4. Freeze regression runtime budget in `state/STATE.md`.

## Acceptance (executable)
- [ ] `make regression` target implemented in Makefile and passes
- [ ] `results/regression.json` generated with complete traceability metadata
- [ ] Regression runtime budget measured and recorded
- [ ] `make check` remains green

   - Define structured test suites covering:

     * L1: Matrix of synthetic shapes, tile configs, weight classes, input classes
     * L2: Real SmolLM2 tiles (8x16, 16x64) with real prompt activations

   - Collect start/end timestamps, durations, vectors tested, mismatches, status.
   - Write out `results/regression.json`.
2. Update Makefile to add `make regression` invoking `verification/regression_runner.py`.
3. Create unit test `tests/test_regression_runner.py` verifying runner behavior and schema of `results/regression.json`.
4. Run `make regression` and `make check`.
5. Freeze regression runtime budget in `state/STATE.md`.
