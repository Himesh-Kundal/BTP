## Goal
Implement a standalone regression runner and Makefile target `make regression`:
1. Execute full verification suite:
   - Level L0 (toy 1x3, 2x4)
   - Level L1 (synthetic shapes across N, K, tile grids, weight and input classes)
   - Level L2 (real SmolLM2 tiles with real captured activations)
   - Level L3 (real SmolLM2 slices across all 7 projection types at layers 0, 14, 29)
   - Cross-simulator verification (Icarus vs Verilator)
   - Static weight audits
   - Full mutation matrix M1–M9
2. Record execution metrics into structured JSON: `results/regression.json` including:
   - git commit hash, timestamp, platform/tool versions
   - per-suite and per-test status, duration, vectors tested, mismatches
   - total tests, passed, failed, wall time
3. Ensure regression is fully reproducible and deterministic.
4. Freeze regression runtime budget in `state/STATE.md`.

## Acceptance (executable)

- [ ] Regression runtime budget measured and recorded
