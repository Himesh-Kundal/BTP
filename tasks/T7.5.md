## Goal
Build and empirically validate an extrapolation model for full transformer layer synthesis costs:
1. Develop linear and sparsity-adjusted per-tile extrapolation models:
   - Model A: Uniform tile sum: $\text{Area}_{\text{extrap}} = N_{\text{tiles}} \times \text{Area}_{\text{tile}} + \text{Area}_{\text{reduction\_tree}}$.
   - Model B: Content-aware / sparsity-weighted model accounting for actual zero rates and magnitude distributions across tiles.
2. Direct Empirical Validation:
   - Synthesize a directly measured larger multi-tile point (e.g. $16 \times 64$ or $32 \times 64$ core).
   - Compare extrapolated area against directly synthesized area.
   - Compute and report error of estimate: $\epsilon = |\text{Area}_{\text{actual}} - \text{Area}_{\text{extrap}}| / \text{Area}_{\text{actual}}$.
3. Label all extrapolated quantities explicitly as "estimate" per spec rules.
4. Save model parameters, predictions, and validation errors in `results/E5.json`.
