# T5.1 — Design P Baseline Generator (W_reg Array and P_bus)
Status: done
Phase/Gate: P5 / G5     Tags: [backend, rtl]     Estimate: 1h
Depends on: T4.5         Spec refs: docs/02 §5, §6, Rule N10, docs/04 §4 (T5.1)

## Goal
Implement `backend/baseline_p.py` to generate the programmable baseline hardware (Design P and Design P_bus) from the same IR `LinearOp` and `TileManifest`:
1. `generate_tile_core_p`: generic tile core for $(N_t, K_t)$ using runtime signed multipliers `x_k * w_nk`.
2. `generate_full_module_p`: complete module containing a `W_reg` register array of size $N' \times K'$ (INT8), loaded via `w_we`, `w_addr` ($\lceil \log_2(N' \cdot K') \rceil$ bits), and `w_data` (8 bits), instantiating tile cores, reduction adder trees over $K$ tiles, constant bias, and registered wrapper with latency $L=1$.
3. `generate_full_module_p_bus`: logic-only variant taking weights as a primary-input bus `w_flat` without `W_reg` storage, for isolated datapath area accounting.
4. Enforce Rule N10: exact width match with Design F ($x: 8$, $w: 8$, product: 16, acc: 32).
5. Ensure clean compilation under `iverilog -Wall`, `verilator --lint-only -Wall`, and Yosys `check -assert`.
