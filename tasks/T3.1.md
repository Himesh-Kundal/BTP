- [ ] `LinearOp` stores dimensions, `TensorRef`s, scales, quant/hw/source metadata
- [ ] JSON + `.npy` serialization round-trip is 100% lossless
- [ ] Invariants I1 (shape consistency), I2 (weights in [-127, 127]), I3 (CONSTANT backend flag), I4 (lossless serialization), I5 (no torch/verilog imports in `ir/`) pass
- [ ] Artifact loader loads dumped SmolLM2-135M layer artifacts into a valid IR object
