## Goal
Implement `backend/verilog_codegen.py` to generate combinational Verilog-2001 tile core modules for arbitrary $(N_t, K_t)$ configurations. The module unpacks `x_flat` into explicitly signed wires, computes dot products against specialized constant weights using `backend/weight_encoder.py`, sign-extends products, and packs outputs into `y_flat` with zero weight ports.
