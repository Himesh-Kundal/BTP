## Goal
Implement `backend/weight_encoder.py` to format INT8 weights as Verilog-2001 signed literals (`8'sd...` / `-8'sd...`) and implement sparsity optimizations: omit zero-weight terms completely, implement $\pm 1$ pass-through / negation wires without multipliers, and generate standard constant multiplier expressions (`*`) for other non-zero weights.

## Acceptance (executable)
- [ ] `pytest tests/test_weight_encoder.py` passes
- [ ] Correctly encodes extreme weights: `-127` (`-8'sd127`), `127` (`8'sd127`), `0` (omitted from dot product), `+1` (wire pass-through), `-1` (negation wire `-x_i`)
- [ ] Strictly follows Verilog-2001 signed literal syntax (no unsigned literals or implicit width expansions)
- [ ] Unit tests verify term count reduction on sparse vectors (e.g., all-zero vector produces zero product terms and constant 0 output)

## Plan (before coding)
- Implement `encode_weight_literal(val: int) -> str` and `generate_mac_term(x_name: str, w_val: int, product_name: str) -> Optional[str]` in `backend/weight_encoder.py`.
- Write unit tests in `tests/test_weight_encoder.py` covering all boundary values (-127, -1, 0, 1, 127) and sparsity rules.
