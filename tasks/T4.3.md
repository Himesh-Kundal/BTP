# T4.3 — Weight Literal Encoder and Sparsity Optimization
Status: in-progress
Phase/Gate: P4 / G4     Tags: [backend, rtl]     Estimate: 1h
Depends on: T4.1         Spec refs: docs/02 §5, §6 (Conventions 1-2), docs/04 §4 (T4.3)

## Goal
Implement `backend/weight_encoder.py` to format INT8 weights as Verilog-2001 signed literals (`8'sd...` / `-8'sd...`) and implement sparsity optimizations: omit zero-weight terms completely, implement $\pm 1$ pass-through / negation wires without multipliers, and generate standard constant multiplier expressions (`*`) for other non-zero weights.

## Acceptance (executable)
- [ ] `pytest tests/test_weight_encoder.py` passes
- [ ] Correctly encodes extreme weights: `-127` (`-8'sd127`), `127` (`8'sd127`), `0` (omitted from dot product), `+1` (wire pass-through), `-1` (negation wire `-x_i`)
- [ ] Strictly follows Verilog-2001 signed literal syntax (no unsigned literals or implicit width expansions)
- [ ] Unit tests verify term count reduction on sparse vectors (e.g., all-zero vector produces zero product terms and constant 0 output)

## Plan (before coding)
- Write failing tests in `tests/test_weight_encoder.py`:
  1. `format_weight_literal`: test -127, -42, -1, 0, 1, 42, 127; verify out-of-range (>127, <-127) raises ValueError.
  2. `encode_product_term`:
     - w=0: returns None (term omitted).
     - w=1: returns pass-through wire with sign extension to 16 bits without `*`.
     - w=-1: returns negation wire with sign extension to 16 bits without `*`.
     - w=42: returns multiplication wire `x_k * 8'sd42`.
     - w=-42: returns multiplication wire `x_k * -8'sd42`.
  3. `encode_row_accumulation`:
     - Dense row: produces K products and sum with explicit 32-bit sign extension.
     - Sparse row (some 0s): zero terms omitted from product list and sum.
     - All-zero row: zero products, sum expression is `32'sd0`.

- Verify with `pytest tests/test_weight_encoder.py` and `make check`.
