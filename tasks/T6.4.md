## Goal
Implement a standalone static weight audit tool in `verification/weight_audit.py`:
1. Parse constant weight expressions and product terms directly from generated Verilog RTL files.
2. Reconstruct the effective quantized weight matrix $W_{\text{RTL}}$ from the parsed AST / regex representations.
3. Compare $W_{\text{RTL}}$ against the golden quantized weights array $W_q$ (from `weights_q.npy` or `LinearOp.weights`) and verify:
   - Complete value equality: $W_{\text{RTL}} == W_q$
   - SHA256 integrity match against the manifest hash
4. Implement negative controls: deliberately inject a single flipped constant or modified weight and verify that `weight_audit.py` fails with an explicit mismatch error.
5. Provide CLI entry point / function usable in automated verification suites.

## Plan (before coding)
- Extend `verification/weight_audit.py`:
  1. Implement `parse_rtl_weights(rtl_source, expected_n, expected_k, manifest=None) -> np.ndarray`:
     - Parses tile module definitions and top-level modules.
     - Decodes Verilog constant product patterns (`* 8'sd<w>`, `* -8'sd<w>`, pass `+1`, negate `-1`, omitted `0`).
     - Assembles tiles into global matrix and extracts unpadded shape $(N, K)$.
  2. Implement `audit_weights_match(rtl_source, expected_weights, manifest=None, strict=True) -> dict[str, Any]`:
     - Verifies exact numerical match $W_{\text{RTL}} == W_{\text{expected}}$.
     - Verifies SHA256 integrity match.
     - Raises `ValueError` under `strict=True` if discrepancies exist.
- Write `tests/test_weight_audit.py`:
  1. Test weight extraction on toy core (1x3).
  2. Test weight extraction on multi-tile synthetic shapes (4x8, 5x11 non-multiple).
  3. Test weight extraction on real SmolLM2 Layer 0 `q_proj` and Layer 14 `gate_proj` modules.
  4. Test negative controls:
     - Mutating a constant value (e.g. 10 -> 11).
     - Flipping literal sign (+12 -> -12).
     - Dropping a product line.
     - Injected hash discrepancy.
     - Verify failure is triggered 100% of the time.
- Verify `make check` remains green.
- Record evidence and merge.
