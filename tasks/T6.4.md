## Goal
Implement a standalone static weight audit tool in `verification/weight_audit.py`:
1. Parse constant weight expressions and product terms directly from generated Verilog RTL files.
2. Reconstruct the effective quantized weight matrix $W_{\text{RTL}}$ from the parsed AST / regex representations.
3. Compare $W_{\text{RTL}}$ against the golden quantized weights array $W_q$ (from `weights_q.npy` or `LinearOp.weights`) and verify:
   - Complete value equality: $W_{\text{RTL}} == W_q$
   - SHA256 integrity match against the manifest hash
4. Implement negative controls: deliberately inject a single flipped constant or modified weight and verify that `weight_audit.py` fails with an explicit mismatch error.
5. Provide CLI entry point / function usable in automated verification suites.
