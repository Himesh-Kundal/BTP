## Goal
Implement Verilator simulation runner and cross-simulator verification:
1. Ensure all generated Verilog-2001 (Design F and Design P) passes `verilator --lint-only -Wall` without warnings or suppressions.
2. Build and run Verilator testbenches (or C++ harness / Verilator lint-clean wrapper) for Level L1/L2/L3 slices.
3. Verify cross-simulator equality: execute identical test vectors under both Icarus Verilog (`iverilog`/`vvp`) and Verilator, verifying byte-identical outputs:
   $$Y_{\text{iverilog}} == Y_{\text{verilator}} == Y_{\text{ref\_int64}}$$
4. Benchmark execution speeds for both simulators to demonstrate Verilator's acceleration for large slices (Level L3/L4).
