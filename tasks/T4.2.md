## Goal
Implement matrix tiling logic in `backend/tiling.py`: slice layer matrix $W \in \mathbb{R}^{N \times K}$ into $N_t \times K_t$ tiles (default $8 \times 16$), pad dimensions to multiples $N' = \lceil N/N_t \rceil \cdot N_t$ and $K' = \lceil K/K_t \rceil \cdot K_t$ with zeros, generate the tile manifest with nonzero weight counts and SHA256 hashes, and verify tiling property guarantees.

## Acceptance (executable)
- [x] `pytest tests/test_tiling.py` passes
- [x] Supports arbitrary tile configurations $(N_t, K_t)$, defaulting to $8 \times 16$
- [x] Zero-pads $W$ and $X$ when $N$ or $K$ is not an exact multiple of $N_t$ or $K_t$
- [x] Tile $(i, j)$ holds $W[i \cdot N_t : (i+1) \cdot N_t, j \cdot K_t : (j+1) \cdot K_t]$
- [x] Tile manifest tracks tile indices $(i, j)$, module name, nonzero count, and SHA256 checksum
- [x] Property tests: tiles cover padded matrix exactly once; padding is strictly zero; unpadded region equals original matrix exactly
