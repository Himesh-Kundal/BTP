## Goal
Implement a unified, robust command-line interface (`llmhw`) unifying the end-to-end compiler and verification toolchain:
1. `llmhw extract`:
   - Extract weight matrices and capture activation samples from SmolLM2-135M (or local artifacts).
   - Flags: `--model`, `--layer`, `--proj`, `--out`, `--num-samples`.
2. `llmhw compile`:
   - Compile a dense linear projection or custom layer to synthesizable Verilog (Design F fixed-weight, or Design P / P_bus baseline).
   - Flags: `--layer`, `--arch`, `--design` (F/P/P_bus), `--tile-n`, `--tile-k`, `--slice-n`, `--slice-k`, `--latency`, `--out`.
3. `llmhw verify`:
   - Validate RTL equivalence against the independent NumPy int64 reference oracle (Claim C1) via Icarus Verilog or Verilator, with automatic static weight audit.
   - Flags: `--rtl`, `--weights`, `--layer`, `--arch`, `--sim`, `--num-vectors`, `--out`, `--dump-vcd`.
4. `llmhw synth`:
   - Run Yosys synthesis flow (generic gates or iCE40 LUT proxy) and emit structured cell/depth metrics.
   - Flags: `--top`, `--rtl`, `--target`, `--flatten`, `--out`.
