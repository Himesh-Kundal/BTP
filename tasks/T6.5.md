## Goal
Extend the mutation suite in `verification/mutate.py` from the prototype (M1–M3) to all 9 fault injection classes defined in `docs/06` §A6:
- **M1**: Flip sign of one weight constant (caught by random vectors)
- **M2**: Change one weight constant by +1 (caught by one-hot vectors)
- **M3**: Drop one product term (caught by one-hot / random vectors)
- **M4**: Swap two input lanes (caught by one-hot vectors)
- **M5**: Reverse packing order of outputs (caught by any asymmetric vector)
- **M6**: Truncate accumulator to 16 bits (caught by sign-aligned worst-case vectors)
- **M7**: Make one multiplication unsigned (caught by negative inputs)
- **M8**: Off-by-one in padding / last lane misrouted (caught by non-multiple shapes)
- **M9**: Add one cycle of latency / delay valid_out (caught by timing check)

Execute the full mutation matrix against the standard test suite.
Enforce **100% kill rate**: any surviving mutant is a bug in the test vectors and must be killed by improving the test suite. Save kill matrix to `results/mutation_matrix.json`.
