## Goal
Implement automated synthesis flow scripts using Yosys for Design F, Design P, and Design P_bus:
1. Target technology mappings:
   - **Generic Gates**: standard gate-level synthesis (`synth -top <top>; stat -json`).
   - **iCE40 LUT Proxy**: FPGA LUT-4 cell mapping (`synth_ice40 -top <top>; stat -json`) as a proxy for fine-grained logic density.
2. Timing / Depth Proxy:
   - Longest topological path via Yosys `ltp` command to extract critical path depth.
3. Structured Metric Parsing:
   - Extract total cells, combinational cells, sequential cells (flops), LUT4 count, wire count, and topological path depth (`ltp`) into structured Python dataclasses and JSON.
4. Determinism & Integrity:
   - Produce bit-for-bit identical synthesis metric JSON for a given RTL and target.

## Acceptance (executable)
- [ ] `synth/yosys_runner.py` implemented with support for Design F, P, and P_bus
- [ ] Generic gate and iCE40 mapping supported
- [ ] `stat` and `ltp` output parsed into structured JSON
