## Goal
Implement a comprehensive test-matrix generator in `verification/test_matrix.py` that systematically covers:
1. Dimensions & tile configurations (Level L1):
   - $N \in \{1, 3, 4, 8, 9\}$, $K \in \{1, 5, 16, 17, 33\}$
   - Tile configurations $\in \{(1, 1), (4, 16), (8, 16), (8, 8)\}$
2. Weight classes (`docs/06` §A5):
   - Uniform random INT8 in $[-127, 127]$
   - Extremes (all $+127$, all $-127$, alternating $\pm 127$)
   - All zero
   - Single nonzero (one-hot weight)
   - Sparse random
   - Near-Gaussian
   - Bias tests: zero bias, synthetic bias vector, extreme bias near $\pm 2^{20}$
3. Input classes (`docs/06` §A4):
   - Class 1: Uniform random INT8 in $[-128, 127]$
   - Class 2: Uniform random within quantizer range $[-127, 127]$
   - Class 3: All $-128$, all $127$, all $0$
   - Class 4: One-hot per lane (value 1 at lane $i$)
   - Class 5: Sign-aligned worst case ($x_k = 127 \cdot \text{sign}(w_k)$ and $-128 \cdot \text{sign}(w_k)$)
   - Class 6: Alternating signs and sparse random
4. Provide runner function to simulate generated matrix cases through Icarus Verilog and verify against `linear_reference_int64` with 0 mismatches.
5. Record execution time budget for `make regression`.
