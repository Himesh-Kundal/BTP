## Goal
Implement and enforce the mandatory fairness protocol (`docs/06` §B2) across all synthesis experiments:
1. Exact script and optimization flag parity between Design F, Design P, and Design P_bus (`flatten`, `opt`, `techmap`).
2. Exact signal width parity (Rule N10): inputs 8-bit, weights 8-bit, products 16-bit, accumulators 32-bit.
3. Registered I/O wrapper parity: identical input/output flip-flop structures.
4. Two distinct reporting accountings for Design P:
   - `P_bus`: Logic-only datapath (weights as primary inputs, no on-chip storage overhead).
   - `P`: Datapath + `W_reg` register storage array.
5. Separate accounting for sequential flip-flops vs combinational cells.
6. Automated fairness assertion test verifying that any mismatched flags or widths raise errors.
