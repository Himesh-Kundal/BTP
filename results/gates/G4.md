## 2. Evidence Summary

- **Constant Weight Specialization (`backend/constant_weights.py`)**:
  - Enforces Invariant I3: only weights with `kind == TensorKind.CONSTANT` are eligible for Design F code generation. Rejects `VARIABLE`, `INPUT`, or non-constant weights with `ValueError`.
  - Audits generated RTL code to strictly reject forbidden port patterns (`input wire [...] w_*`) and ensure weights are completely embedded into the logic.
  - Verified in [`tests/test_constant_weights.py`](file:///home/himesh/BTP/tests/test_constant_weights.py).

- **Parametric Tiling & Zero-Padding (`backend/tiling.py`)**:
  - Mathematically sound decomposition: decomposes arbitrary $(N, K)$ matrix into $\lceil N/N_t \rceil \times \lceil K/K_t \rceil$ tiles with zero-padding.
  - Generates immutable `TileSpec` records and JSON-serializable `TileManifest` containing SHA256 hashes of the original matrix and all tile arrays.
  - Exact property validation:
    - Reconstruction property: $\sum_{j} X_{\text{padded}}[:, j] \cdot W_{\text{tile}}[i, j]^T = (X_{\text{padded}} \cdot W_{\text{padded}}^T)[:, i]$.
    - Dimension roundtrip: `unpad_outputs(pad_activations(X) @ pad_matrix(W).T, N) == X @ W.T`.
  - Tested on both exact multiples (SmolLM2 $576 \times 576$ and $1536 \times 576$) and non-multiples ($5 \times 11$ tiled to $8 \times 16$) in [`tests/test_tiling.py`](file:///home/himesh/BTP/tests/test_tiling.py).

- **Weight Literal & Arithmetic Encoding (`backend/weight_encoder.py`)**:
  - Formats signed literals strictly in Verilog-2001 syntax: `8'sd<val>` for positive, `-8'sd<abs_val>` for negative.
  - Algebraic term simplifications:
    - $w = 0$: completely omitted from accumulation expressions (zero hardware cost).
    - $w = +1$: direct signed pass-through wire `x_k`.
    - $w = -1$: multiplier-free signed negation wire `-x_k`.
    - $|w| > 1$: explicit signed 16-bit wire `wire signed [15:0] prod_... = x_k * weight_literal;`.
  - Explicit 32-bit sign extension using `$signed({{16{prod[15]}}, prod})`.
  - Verified in [`tests/test_weight_encoder.py`](file:///home/himesh/BTP/tests/test_weight_encoder.py).

- **Tile Core Generator (`backend/verilog_codegen.py`)**:
  - Emits standalone combinational Verilog-2001 tile core modules with flat bitvector packing: `x_flat` $[8 \cdot K_t - 1 : 0]$ and `y_flat` $[32 \cdot N_t - 1 : 0]$.
  - Includes scoped Verilator pragmas (`/* verilator lint_save */ ... /* verilator lint_restore */`) ensuring clean compilation under both `iverilog -Wall` and `verilator --lint-only -Wall`.
  - Bit-exact golden vector comparison against NumPy INT64 reference oracle.
  - Verified in [`tests/test_verilog_codegen.py`](file:///home/himesh/BTP/tests/test_verilog_codegen.py).

- **Full Module Generator & Registered Wrapper (`backend/module_generator.py`)**:
  - Instantiates grid of tile cores, reduction adder tree over $K$ tiles ($j = 0 \dots \text{num\_k\_tiles}-1$), and optional constant bias addition.
  - Registered wrapper provides clean pipeline timing with manifest latency $L=1$:
    - Synchronous active-low reset `rst_n` driving ONLY `valid_out <= 1'b0`.
    - Datapath registers `y_flat <= y_comb` on `clk` without reset (avoiding unnecessary reset routing and area overhead).
  - Cleanly unpads output bitvector: only exports $32 \cdot N$ bits for the true original output channels; padding lanes remain internal.
  - Live simulation in Icarus Verilog:
    - Real SmolLM2 Layer 0 `q_proj` $8 \times 16$ tile: PASS (`CHECKED=10, MISMATCH=0, TIMING_ERR=0`).
    - Non-multiple shape ($N=5, K=11$ tiled to $8 \times 16$): PASS (`CHECKED=10, MISMATCH=0, TIMING_ERR=0`).
  - Verified in [`tests/test_module_generator.py`](file:///home/himesh/BTP/tests/test_module_generator.py).

- **Interface Conformance & Static Weight Audit Engine (`verification/weight_audit.py`)**:
  - Comment-stripping static analyzer verifying 0 weight ports, 0 `w_*` signals, 0 writable storage arrays (`reg [...] mem [...]`), and exact port widths matching IR specifications.
  - Negative control battery proven to catch and kill:
    - Injected weight input ports (`input wire [7:0] w_in`)
    - Injected weight internal signals (`wire signed [7:0] w_data`)
    - Injected writable memories (`reg signed [7:0] weight_rom [0:15]`)
    - Injected simulation delays (`#10`) and display statements (`$display`)
  - Verified in [`tests/test_interface_conformance.py`](file:///home/himesh/BTP/tests/test_interface_conformance.py).

- **RTL Generation Determinism & Frozen Budgets (`backend/module_generator.py`, `tests/test_determinism.py`)**:
  - 100% byte-identical SHA256 hashes on repeated runs.
  - Stripped of nondeterministic artifacts (no timestamps `YYYY-MM-DD`, no absolute paths `/home/...`).
  - Frozen benchmark budgets on full $576 \times 576$ SmolLM2 linear projection layer (2,592 tiles):
    - **Generation Time**: `0.168s`
    - **RTL Line Count**: `224,750 lines`
    - **RTL File Size**: `7.33 MB` (7,682,752 bytes)
    - **Icarus Verilog Compilation**: Compiles with `-Wall` with 0 warnings in ~11s.
    - **Yosys AST & Assert Check**: Clean (`check -assert` exit code 0).
