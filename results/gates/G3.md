## 2. Evidence Summary
- **IR & Serialization Integrity**:
  - `TensorRef` tracks shape, dtype, `kind` (`CONSTANT`, `INPUT`, `OUTPUT`), array data, path, and SHA256 checksums.
  - JSON + `.npy` sidecar serialization round-trip is 100% bit-exact. Tampered sidecars trigger immediate SHA256 mismatch rejection.
  - Invariants validated:
    - I1 (Shape consistency across $W, b, X$)
    - I2 (Quantized weights strictly within $[-127, 127]$, rejecting $-128$)
    - I3 (Weight marked `CONSTANT` for fixed hardware)
    - I4 (Lossless serialization)
    - I5 (0 PyTorch/Transformers imports in core modules)
- **Quantization Properties (Rule N2)**:
  - Per-output-channel symmetric scale $s_w[n] = \max |W[n, :]| / 127.0$ computed in float64.
  - Round-half-to-even tie breaking analytically and empirically verified.
  - Bound property $|W - s_w \cdot W_q| \le s_w/2 + 10^{-12}$ verified on 10 randomized matrices across dynamic ranges.
  - Zero-row corner cases map cleanly to $s_w = 1.0$ and zero row output.
- **Activation Calibration (Rule N3)**:
  - Static per-tensor scalar scale $s_x = \text{stat} / 127.0$ calibrated on fixed prompts with deterministic seed 42.
  - Quantized activations strictly in $[-127, 127]$. Rerun determinism verified.
- **Bias Scaling (Rule N5)**:
  - Quantized into INT32 domain with scale $s_b[n] = s_x \cdot s_w[n]$.
  - Bit-exact agreement between $X_q @ W_q^T + b_q$ and independent NumPy INT64 reference oracle.
- **Accumulator Bitwidth Pass (Rule N4, N8)**:
  - Worst-case dot product bound $K \cdot 128 \cdot 127 + |b_q|_{\max}$ analytically proven safe:
    - $K=576 \implies \text{bound} = 9,363,456 \implies 25\text{ bits}$
    - $K=1536 \implies \text{bound} = 24,969,216 \implies 26\text{ bits}$
  - Both safely fit within signed 32-bit limit ($2^{31}-1 = 2,147,483,647$).
  - Rejection threshold $\ge 2^{31}$ verified ($K \ge 132,105$ rejected).
- **Claim C2 Evaluation & Change Control**:
  - Full evaluation across all 21 configurations (7 projections $\times$ layers {0, 14, 29}) recorded in `results/quant_quality.json`.
  - Statistics:
    - Cosine similarity: min `0.988700`, mean `0.997881`, max `0.999844`
    - SQNR: min `16.36 dB`, mean `26.93 dB`, max `35.01 dB`
    - Relative L2 error: min `0.0178`, mean `0.0519`, max `0.1520`
  - ADR-0001 accepted, freezing thresholds at:
    - Cosine similarity $\ge 0.980$
    - SQNR $\ge 15.0\text{ dB}$
    - Relative L2 error $\le 0.180$
- **End-to-End Compiler Pipeline (`compiler/pipeline.py`)**:
  - Orchestrates calibration $\to$ quantization $\to$ accumulator bounds $\to$ hardware specialization.
  - Tested on real SmolLM2-135M layer 0 `q_proj`.
- **Regression Suite**:
  - 95 tests passing in `make check`.
